# 시연 규칙 — army-pr360 참조파일 ③

> **용도** : 모든 모드가 **출력을 내보내기 직전에** 이 파일을 확인한다.
> **성격** : 품질 규칙이 아니라 **실격 방지 규칙**이다. 하나라도 어기면 점수가 의미 없어진다.

---

## 1. 안전 표시 6종 — 출력에 항상 붙인다

| # | 표시 | 막아주는 질문 |
|---|---|---|
| ① | **합성 데이터** | "실제 개인정보를 쓴 겁니까?" |
| ② | **사전 생성 결과 / 로컬 규칙 재계산** | "방금 만든 겁니까, 미리 만든 겁니까?" |
| ③ | **출처 문서명 · 기준일** | "AI가 모집 일정을 틀리게 말하면 어떻게 합니까?" |
| ④ | **왜 이 추천인가 (근거 지표 · 표본 수)** | "왜 이 추천입니까?" |
| ⑤ | **초안 · 검토 후 사용** | "AI가 쓴 게 그대로 대외로 나갑니까?" |
| ⑥ | **실제 발송 기능 없음** | "실수로 발송되면 어떻게 합니까?" |

**화면이 미리 답하면 질문이 줄어든다.** 이 6종을 화면에서 지우지 않는다.

---

## 2. 용어 — 「가명」이 아니라 「합성」

| ✕ 쓰지 않는다 | ○ 이렇게 쓴다 |
|---|---|
| 가명 처리된 자료 | **합성 데이터** |
| 익명화한 실제 데이터 | **실존 인물·기관과 무관하게 새로 만든 자료** |

> **이유** — 「가명정보」는 **실존하는 개인정보를 가공한 것**이라 개인정보보호법 적용 대상이다.
> "가명 처리했습니다"라고 하면 **"그럼 원본 개인정보가 있다는 말입니까?"** 라는 질문이 따라온다.
> "합성 데이터입니다. 실존 인물의 정보를 가공한 것이 아닙니다."라고 해야 질문이 끝난다.

**표준 문구**
> 본 자료의 모든 데이터는 실존 인물·기관과 무관하게 만든 **합성 데이터**이며,
> 실제 운영 시 개인 식별정보는 수집하지 않고 집계값만 저장합니다.

## 3. 금지 사항

### 3-1. 데이터
- ✕ 실제 부대명 · 실제 학교명 · 실명 사용
- ✕ 개인 식별정보 필드 생성 (이름·연락처·주민번호·학번 등)
- ✕ 개인별 실적 순위 표시

### 3-2. 심사 (블라인드)
- ✕ 소속 부대명 · 계급 · 성명 · 부대 마크 노출 (문서·화면 **양쪽**)
- ○ 대체 표현 : **"현장 모집홍보 업무 수행자"**

### 3-3. 저작권 · 실격
- ✕ 상용 서비스 의존 (**Canva 등 일절 사용하지 않는다**)
- ✕ 외부 폰트·아이콘 중 상업적 이용이 허용되지 않은 것
- ✕ 육군 CI·엠블럼·병과 마크 중 공식 배포 자료가 아닌 것
- ✕ 출처 없이 인용한 문장 (표절률 20% 초과 시 실격)

### 3-4. 과대 약속
- ✕ "AI가 완성 포스터를 자동 생성합니다"
- ○ **"사람이 검수할 기획안을 만듭니다"**
- ✕ 근거 없는 수치 ("80% 단축" 등)
- ○ 측정한 값만 쓰고 **표본 수를 함께 밝힌다**

### 3-5. 발송
- ✕ **메일·메시지 발송 버튼을 만들지 않는다**
- → 버튼이 없으면 "실수로 나갈 수 있느냐"는 질문 자체가 성립하지 않는다

## 4. 사실 정보 인용 규칙

모집 일정 · 지원 자격 · 선발 절차 등 **사실 정보**는 다음을 지킨다.

1. **승인된 공식 자료에서만** 인용한다.
2. 인용한 **문서명과 기준일**을 화면에 표시한다.
3. 확인되지 않은 사실은 **생성하지 않고** `[확인 필요]`로 표기한다.
4. 대외로 나가는 산출물은 **사람 승인 후에만** 확정 상태가 된다.

**표기 형식**
```
※ 인용 : 「○○○ 모집 공고」 (기준일 2026-08-01) · 검토 상태 : 초안
```

## 5. 시연 상태 표시 규칙

| 상태 | 배지 | 멘트 |
|---|---|---|
| 내장된 사전 생성 결과를 재생 | **「사전 생성 결과」** | "미리 생성하고 검증한 결과입니다" |
| 내장 데이터로 지표·추천을 다시 계산 | **「로컬 규칙 재계산」** | "지금 이 자리에서 규칙대로 다시 계산한 결과입니다" |

> **⚠ 2026-08-16 변경 — 「실시간 생성」이라는 표현을 쓰지 않는다.**
> GATE4-A 데모 앱(`Army_PR360_Lite.html`)은 **오프라인·API 키 없음**이므로 실시간 AI 호출이
> 물리적으로 일어나지 않는다. 그런데 화면에 「실시간 생성」이라 쓰면 **로컬 재계산 결과를
> "지금 AI가 만들었다"로 오인하게 만든다** — 아래 「절대 하면 안 되는 것」과 정확히 같은 사고다.
> 앱이 실제로 하는 일(규칙 재계산)을 그대로 이름으로 쓴다.

### 절대 하면 안 되는 것
캐시 결과가 떠 있는 상태에서 **"지금 O초 만에 만들어졌습니다"** 라고 말하는 것.
나중에 밝혀지면 **시연 조작**으로 읽힌다. 앱 경진대회에서 이보다 치명적인 사고는 없다.

→ **배지를 화면에 자동 표시해 두면 이 사고 자체가 불가능해진다.**

### 「실시간 AI가 아니지 않습니까?」 질문에 대한 답변 (개정판)
> "이 데모는 인터넷이 끊겨도 도는 오프라인 파일이라, 화면에서 도는 것은 **규칙 엔진**입니다.
> AI 생성은 이미 끝났습니다 — Cowork 스킬이 생성하고 **사람이 검증한 뒤 내장**했습니다.
> 검증되지 않은 AI 출력이 현장 도구에서 그대로 나가는 게 오히려 위험하다고 봤습니다.
> 그래서 화면에도 '실시간 생성'이라고 쓰지 않고 **'로컬 규칙 재계산'이라고 정확히 표시**했습니다."

## 6. 출력 전 자가 점검 5문

모든 모드는 출력 직전에 스스로 확인한다.

1. 실명·실제 학교명·실제 부대명이 들어갔는가? → 있으면 **합성 명칭으로 치환**
2. 소속·계급·성명이 노출됐는가? → 있으면 **삭제**
3. 근거 없는 수치를 썼는가? → 있으면 **삭제하거나 표본 수 병기**
4. 사실 정보에 출처·기준일이 붙었는가? → 없으면 **`[확인 필요]` 표기**
5. 안전 표시 6종 중 해당하는 것이 붙었는가? → 없으면 **추가**
